# Документация по флагам и параметрам обучения (CLI)

В данном проекте используются единые параметры и флаги командной строки для всех обучающих скриптов (`train_resnet.py`, `train_efficientnet.py`, `train_vit.py`, `train_clip.py`). Ниже приведено полное описание всех доступных флагов.

## Базовые параметры путей и запусков

* `--data-root` — Путь к корневой папке датасета DeepFashion (по умолчанию берётся из конфига).
* `--output-dir` — Базовая папка, куда будут сохраняться результаты. Для ResNet по умолчанию это `runs/`, для остальных — `runs/имя_архитектуры`.
* `--run-name` — Имя подкаталога эксперимента внутри `--output-dir` (например, `resnet50_lr3e4_bs32`). Если не задано, сгенерируется автоматически с timestamp.
* `--overwrite-output` — Разрешить запись в существующую непустую папку (иначе будет создана новая папка с добавлением даты/времени к имени).

## Выбор модели (только для специфичных скриптов)

* `--variant` — Выбор варианта модели:
  * Для `train_efficientnet.py`: `b0` (по умолчанию), `b2`, `b3`.
  * Для `train_vit.py`: `b_16` (по умолчанию), `b_32`.
  * Для `train_clip.py`: `ViT-B-32` (по умолчанию), `ViT-B-16`, `ViT-L-14`.
* `--freeze-backbone` — (Только для `train_clip.py`) Заморозить веса энкодера изображений CLIP (режим Linear Probing). Обучаются только финальные линейные слои (головы).

## Гиперпараметры обучения

* `--epochs` — Количество эпох обучения.
* `--batch-size` — Размер батча (по умолчанию из конфига, обычно 32).
* `--lr` — Исходный Learning Rate (скорость обучения).
* `--weight-decay` — Коэффициент Weight Decay (регуляризация L2). Очень важен для ViT и CLIP (обычно 0.01 - 0.3).
* `--image-size` — Размер изображения (разрешение, до которого скейлятся фото, например 224).
* `--loss-weight-type` — Вес функции потерь для задачи классификации типа (по умолчанию 1.0).
* `--loss-weight-color` — Вес функции потерь для задачи классификации цвета (по умолчанию 1.0).
* `--loss-weight-style` — Вес функции потерь для задачи классификации стиля (по умолчанию 1.0).
* `--no-amp` — Отключить смешанную точность (AMP - Automatic Mixed Precision) на CUDA. Если не указано, AMP используется по умолчанию для ускорения.

## Ранняя остановка (Early Stopping)

* `--patience` — Количество эпох без улучшений усреднённой метрики `val_avg_macro_f1` (по трём задачам) для ранней остановки (0 = отключено).
* `--min-delta` — Минимальное улучшение метрики, чтобы считаться прогрессом (по умолчанию 0.001).

## Управление данными и семплированием

* `--seed` — Фиксированный сид генератора случайных чисел для воспроизводимости.
* `--full-dataset` — Использовать все доступные на диске изображения (~289k).
* `--max-samples` — Явное ограничение количества образцов. Если не указано (и нет `--full-dataset`), берётся `default_max_samples` из конфигурации (по умолчанию 20,000).
* `--subset-selection` — Стратегия усечения датасета:
  * `stratified` (по умолчанию) — случайная стратифицированная подвыборка с сохранением долей классов.
  * `first_n` — взять просто первые N строк из файлов аннотаций.
* `--rebuild-splits` — Принудительно пересоздать разделение на train/val/test, даже если на диске уже есть файл `splits.npz`.
* `--num-workers` — Количество процессов для загрузки данных при обучении (train_loader).
* `--eval-num-workers` — Количество процессов для загрузки данных при валидации/тестировании. На Windows рекомендуется 0.

## Стратификация и балансировка классов (в особенности для стилей)

Из-за сильного дисбаланса стилей (длинный хвост редких стилей) метрика `style_macro_f1` может сильно занижаться. Следующие флаги помогают бороться с этим.

* `--min-style-frequency N` — Если больше 0, полностью удаляет из рассмотрения фото, чей стиль встречается во всём датасете реже `N` раз. Отрезает самый "длинный хвост".
* `--split-stratify` — По каким меткам осуществлять стратифицированное разбиение на train/val/test:
  * `type` (по умолчанию) — только по типу одежды.
  * `type_coarse_style` — по типу и "грубому" стилю (редкие стили объединяются в одну категорию чисто для сплита).
  * `style_coverage` — **(Рекомендуемый для стилей)** гарантирует попадание каждого стиля в каждую выборку (train/val/test).
* `--style-stratify-min-freq` — (Используется с `type_coarse_style`) Порог частоты, ниже которого стили считаются "редкими" и объединяются в одну корзину при стратификации. По умолчанию 5.

### Эквализация стилей (Style-balanced subset)

Эти флаги позволяют отобрать подвыборку (из того, что ограничено `--max-samples`), в которой будет одинаковое количество фотографий на каждый стиль. 

* `--style-balanced-subset` — Включить режим уравнивания (ограничения) примеров на стиль.
* `--style-balance-min-keep N` — Стиль должен иметь как минимум `N` фотографий в текущей выборке, чтобы вообще остаться в ней (остальные отбрасываются). По умолчанию 3.
* `--style-balance-per-style K` — Точное количество фотографий, оставляемое на каждый стиль. Если не указано, алгоритм сам посчитает максимально возможный K для текущего `--max-samples`.

---
*Примечание:* Аналогичные параметры можно задавать в YAML файлах планов для `run_experiments.py` в блоках `common_params` и `params`. Флаги преобразуются автоматически (например, `freeze_backbone: true` станет `--freeze-backbone`).
